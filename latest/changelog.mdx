<Update label="14th September 2026" description="2026.09.14">

    ## Features

    - Trial status is now visible in the header — a badge shows how many days are left on your trial, changing colour as it nears expiry. If you hit a plan limit, such as deploying a project, adding an environment, or chatting with the AI, you'll see a clear message explaining what's blocked and how to unlock it.
    - Arriving from an Avalara promotion now tailors your Build experience: the welcome message and example prompts focus on AvaTax and other Avalara integrations to help you get started faster.

    ## Improvements

    - The skills marketplace now uses consistent "Install" / "Installed" language throughout, and skill tags now distinguish skills installed from the marketplace from ones your organisation created or uploaded.
    - General styling and layout refinements across the Skills experience, including the upload skill dialog.
    - You can keep typing in the chat message box while the AI is still responding, and it no longer loses focus after you send a message.
    - Deployment status messaging is clearer, and the deployment banner now fills the available width correctly.

    ## Bug fixes

    - Fixed an issue where a skill already added to your organisation from the marketplace could still appear as available to add, instead of showing as installed.
  
</Update>
<Update label="11th September 2026" description="2026.09.11">

    ## Bug fixes

    - Fixed an issue in the skills marketplace where a skill already added to your organisation could still show an "Add" button instead of reflecting its installed status.
    ## Features

    - A new skills marketplace is available under Skills: browse, search, filter, sort, and install skills for your organisation. You can also upload your own skills from a single file or a folder, including a README and a product image.
    - The Skills page is now available to everyone, not just Versori accounts.
    - You can now install marketplace skills directly from a Build or Plan conversation. The planning agent can recommend skills and install them for you, and chat cards show what each skill action did — what a search matched, which skill was loaded, and which file was read.
    - Chats now show a context usage bar so you can see how full the conversation's context window is as you work.

    ## Improvements

    - Skills replaces Resources in the navigation, with a refreshed layout: larger header actions, aligned search/tiles/page spacing, taller tiles, and a category filter dropdown (with a clear-all action) in place of category tiles.
    - Creating a new integration no longer prompts you to choose skills. Mandatory skills are attached automatically in the background, and skills are now managed at the organisation level only rather than per project.
    - Marketplace install counts and the "most installed" sort are hidden until that data is ready, and the skills count badge is hidden when a list is empty.

    ## Bug fixes

    - Fixed an issue where planning artifacts could be lost or overwritten mid-response; they now save reliably as the agent works.
    - Fixed the skill editor discarding unsaved edits on refresh, dropping some fields when saving a skill, and failing to load certain skills.
    - Fixed missing tooltips on skill-related chat cards, and fixed the install-skill card being unusable in the legacy Plan tab.
    - Fixed an incorrectly cropped Avalara icon shown against the Avalara category in the skills marketplace.
</Update>

<Update label="23rd September 2026" description="2026.09.23">

    ## Features

    - **Issue Watcher.** When a deployed integration fails, Issue Watcher investigates the failure and proposes a fix
      for you to review. It reads the version actually running, works from the failing execution's trace and logs, and
      saves the smallest change it can as a draft version with a written report. Nothing is deployed automatically.
      See [Issue Watcher](/latest/guides/getting-started/monitor/issue-watcher).
    - **Cloud Agents.** Issue Watcher is the first of a family of agents that run on the platform rather than in your
      chat, doing a standing job on your behalf whether or not you are watching. Agents belong to your organisation,
      and you attach one to the work you want it to do. See [Cloud Agents](/latest/ai-tooling/cloud-agents).

</Update>

<Update label="09th September 2026" description="2026.09.09">

    ## Features

    - **Skills marketplace.** Browse a catalogue of ready-made skills and add them to your organisation, instead of
      writing every skill yourself. Fork any marketplace skill to get an editable copy of your own. The AI can also
      suggest a relevant skill while you work, and nothing is added unless you approve it. See the
      [Skills Marketplace](/latest/ai-tooling/marketplace).
    - **Skills have moved to their own page.** Your organisation's skills are now under **Skills** in the left-hand
      navigation, rather than in organisation settings, with search, category and status filtering, and sorting.
      See [Manage Your Skills](/latest/ai-tooling/manage-skills).

    ## Improvements

    - Skills now apply across your whole organisation, so there is no longer a per-integration step to attach them.
      Adding a skill is what makes it available. Mark one as **Mandatory** to apply it to every request, or leave it
      **Optional** to be loaded when its description matches the work in hand. See
      [How the AI applies skills](/latest/ai-tooling/skills#how-the-ai-applies-skills).

</Update>

<Update label="22nd January 2026" description="2026.01.22">
